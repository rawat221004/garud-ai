# Security

Use GitHub's **Report a vulnerability** action in the repository's Security tab. Include the affected version, expected behavior, and affected component. Leave credentials and real incident records out of the report. If private reporting is unavailable, open a minimal issue asking for a private channel and keep the details private.

Run the demo against a local instance with synthetic data. The prototype lacks production authentication and authorization. Before deployment, add access controls, retention and privacy policies, and operational review.
